## 🐳 Containerized Deployment (Docker)

To run the interactive exam simulator locally inside a lightweight Docker container (via Nginx):

1. **Build the Docker Image** (run this from inside the `13-AWS-Cloud-Practitioner-Exam/` directory):
   ```bash
   docker build -t aws-exam-simulator .
   ```

2. **Run the Container**:
   ```bash
   docker run -d -p 8080:80 --name exam-simulator aws-exam-simulator
   ```

3. **Access Endpoint**:
   Open your browser and navigate to: **[http://localhost:8080](http://localhost:8080)**
