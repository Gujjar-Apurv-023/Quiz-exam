### **Question 1**
AWS Elastic Beanstalk is a service that manages web infrastructure.
*   A. True
*   B. False

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **A. True**
*   **Explanation:** **AWS Elastic Beanstalk** is a Platform-as-a-Service (PaaS) designed to quickly deploy and scale web applications. It automatically handles deployment details like capacity provisioning, load balancing, auto-scaling, and health monitoring, which effectively manages the underlying web infrastructure on your behalf.
</details>

### **Question 2**
Which AWS service reduces network latency?
*   A. Amazon CloudFront
*   B. AWS Transit Gateway
*   C. Elastic Load Balancing
*   D. AWS Direct Connect

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **A. Amazon CloudFront**
*   **Explanation:** **Amazon CloudFront** is a Content Delivery Network (CDN) service that caches content at edge locations worldwide. By serving data, videos, applications, and APIs from locations closer to users, it dramatically reduces network latency.
</details>

### **Question 3**
What kind of database is AWS DynamoDB?
*   A. Relational database
*   B. NoSQL database
*   C. Document database

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **B. NoSQL database**

### **Question 9**
Denial-of-Service (DoS) attacks come from different sources.
*   A. True
*   B. False

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **B. False**
*   **Explanation:** A **Denial-of-Service (DoS)** attack originates from a **single source** (one computer or network connection). In contrast, a **Distributed Denial-of-Service (DDoS)** attack originates from **different / multiple sources** (e.g., a botnet).
</details>

### **Question 11**
Which of the following is an AWS Migration Strategy?
*   A. Auditability
*   B. Replatforming
*   C. Governance

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **B. Replatforming**
*   **Explanation:** **Replatforming** (sometimes called "lift-tinker-and-shift") is one of the standard migration strategies defined in the AWS 7 Rs model. </details>

### **Question 22**
If an instance store reboots, does the data in the instance persist?
*   A. Yes
*   B. No

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **A. Yes**
*   **Explanation:** Data stored in an **EC2 Instance Store** persists when the instance reboots. However, the data will be lost if the instance is stopped, terminated, or if the underlying host hardware fails (which is why instance store is called ephemeral).
</details>

### **Question 27**
AWS Elastic Block Store (EBS) Snapshots are:
*   A. Full data backups
*   B. Incremental data backups
*   C. Differential data backups

<details>
<summary><b>👁️ Reveal Answer & Explanation</b></summary>

*   **Correct Answer:** **B. Incremental data backups**
*   **Explanation:** **EBS Snapshots** are incremental backups. This means only the blocks of data that have changed since your last backup snapshot are copied and billed, minimizing storage space requirements.
